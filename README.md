# Bella — support site

Public support, privacy, terms and account-deletion pages for the
**BellaBella** iOS app (bundle `com.fixedgirl.Bella`).

Served by GitHub Pages at <https://hashtagcoin.github.io/bella-support/>.

The privacy policy describes the Supabase-backed build of Bella 1.0. If the app's
data handling changes, update `privacy.html` before shipping the new version —
Apple checks that the policy matches the submitted binary.
